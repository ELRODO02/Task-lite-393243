Esencial para MVP
1. Registrar tareas — Permite capturar el trabajo que el equipo necesita realizar.
2. Visualizar tareas registradas — Da al equipo una vista clara del trabajo existente.
3. Consultar el estado de cada tarea — Permite saber rápidamente qué tareas están pendientes o avanzando.
4. Actualizar el estado de una tarea — Hace posible reflejar el progreso real del trabajo.
5. Persistir las tareas y sus cambios — Evita perder la información y permite continuar el seguimiento posteriormente.
Posterior
6. Editar información de una tarea — Permite corregir o actualizar sus datos después de haberla registrado.
7. Eliminar tareas — Ayuda a retirar tareas que fueron creadas por error o que dejaron de ser necesarias.
8. Filtrar tareas por estado — Facilita encontrar y enfocarse en un grupo específico de tareas cuando la cantidad aumente.
